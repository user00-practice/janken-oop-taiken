# 完成コード・講師デモ（講師専用）

各STEPの完成コードと、講師デモ用のコードです。このフォルダは受講者用リポジトリには同期されません。

## 開き方

1. IntelliJ IDEA のメニュー「ファイル」→「開く...」で、この `answer` フォルダを選ぶ（リポジトリ全体ではなく `answer` フォルダ）
2. 「新しいウィンドウ」を選び、「プロジェクトを信頼」を押す
3. 実行構成の一覧から「解答 STEP1 CUI版」などを選んで実行する

受講者用のスターターと同じパッケージ名・クラス名を使っているため、別のプロジェクトとして開く構成にしています。

| フォルダ | 内容 |

| `step1-cui` | STEP1 の完成コード |
| `step2-gui-oop` | STEP2 の完成コード（受講者用 `step3-multi` の出発点と同じ内容） |
| `step3-multi` | STEP3 の完成コード |
| `demo-cui-multi` | 講師デモ用：STEP1 の CUI版を「あなた＋CPU 3人」に拡張したもの |

## 講師デモ（demo-cui-multi）の使い方

STEP3 に入る前に投影します。CUI版のまま人数を増やすと、次のようになることを見せます。

- CPU ごとに、手・表示名・勝った回数の変数が必要になる
- 手を表示する switch 文を、人数分コピーすることになる
- 勝ちの判定も、1人ずつ調べる if 文が人数分並ぶ

ソースコードの「★」の付いた行（42行）が、CPU を4人目に増やすときに書き足し・書き直しが必要な場所です。OOP版（`step3-multi`）では、`JankenGame` の `CPU_COUNT` を 3 → 4 にするだけで済みます。この対比が、本コースの一番伝えたい点です。

## STEP3 で変更するのは JankenGame だけ

`step2-gui-oop` と `step3-multi` を比べると、`Hand`・`Player`・`CpuPlayer`・`Main` は1行も変わっていません（画面の `MainFrame` は人数分のラベルを作るよう変更済みの状態で配っています）。受講者が書き換えるのは `JankenGame` だけです。まとめのときに、IntelliJ でファイルを比較して見せると効果的です（2つのファイルを選んで、ファイルの比較〈Ctrl+D〉）。
